# Hidaya Analytics

Executive analytics dashboard for Hidaya app data.

## Current status

The dashboard frontend is being prepared for deployment under `/analytics/`. The verified snapshot summary is dated 2026-10-02:

- Android unique users: 40,592
- iOS unique devices: 7,500
- Combined snapshot: 48,092

These are snapshot figures, not sums of daily records. Daily source metrics should retain their individual definitions.

## Local project files

The working frontend currently includes a standalone `index.html` with the source data embedded. It must be uploaded to this directory before the GitHub Pages URL can serve the actual dashboard.
